# TryHackMe Write-ups

Write-ups from completed TryHackMe rooms, focused on methodology and thinking rather than step-by-step walkthroughs.

## Format for each write-up
Each room gets its own file (`room-name.md`) with:
- **Room:** name and link
- **Objective:** what the room was testing
- **Approach:** how I found/exploited the vulnerability
- **Key finding:** the core vulnerability or technique
- **Detection/Remediation:** how this would be caught or fixed in a real environment
